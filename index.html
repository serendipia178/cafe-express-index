Ayuda

Cómo obtener el token en GitHub
  1. En Inicio pulsa Editar y obtener token. Se abre GitHub con el permiso repo ya preparado.
  2. Comprueba que la nota sea coffeb, la caducidad 7 días y que solo esté marcado repo.
  3. Pulsa Generar token y copia el texto ghp_…. Solo se muestra una vez.
Cómo obtener el token en Codeberg
  1. Entra en codeberg.org → foto de perfil → Settings → Applications.
  2. Escribe un nombre. En repository elige Read and Write y en user elige Read.
  3. Pulsa Generate Token y copia el texto. Solo se muestra una vez.
Cómo cuido tu privacidad
  • El token vive solo en la memoria de esta pantalla. No se escribe en el dispositivo; lo único que se recuerda es tu elección de modo claro u oscuro.
  • La app solo puede conectarse a api.github.com y codeberg.org, y a codeberg.page para comprobar tu página ya publicada (sin enviar tu token). El navegador bloquea cualquier otro destino.
  • Tu archivo va directo a tu cuenta, sin servidores intermedios.
  • El campo del token se vacía al terminar la publicación.
  • El informe de incidencias no incluye el token ni tu archivo y solo se envía si pulsas «Enviar por correo».
  • COFFEB-C solo entra en la cuenta a la que pertenece el token que tú pegas. No puede acceder a cuentas ajenas.
  • El proyecto será público: no incluyas datos personales en tu aplicación.
  • El token sigue activo en GitHub hasta que caduque. Bórralo cuando termines de probar.
Si algo falla
  • Token rechazado: revisa que esté completo, vigente y con el permiso repo.
  • Error 404 al abrir el enlace: espera un par de minutos y recarga.
  • Codeberg dice «Not Found»: Codeberg publica el sitio al recibir un aviso (webhook) del proyecto. COFFEB-C lo configura solo; si lo creaste antes con una versión anterior, vuelve a publicar con el mismo nombre y acepta reemplazar.
  • Sin conexión: comprueba tu internet y vuelve a intentarlo.

¿Algo no funciona?

Genera un informe técnico (sin tu token ni tu archivo) para enviarlo por correo o copiarlo.
